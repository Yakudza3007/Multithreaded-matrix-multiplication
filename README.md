# Лабораторная работа №2: Многопоточное умножение матриц

Данный проект реализует многопоточное умножение матриц на языке C# (.NET 10.0) с ручным управлением потоками.

##  Структура проекта
*   `*.cs` — исходный код программы (классы для работы с матрицами, потоками, IPC и бенчмарками).
*   `Data/` — папка с результатами экспериментов.

##  Как запустить проект
Замеры следует проводить **только в конфигурации Release** (для отключения отладочных проверок и правильного замера времени).

В терминале пропишите:
```bash
dotnet run -c Release
